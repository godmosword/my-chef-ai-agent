# 法務與資料政策（草案）

## 1) 食譜與健康免責

- 本服務提供之食譜、成本估算與建議僅供參考，不構成醫療、營養或專業飲食建議。
- 使用者應自行確認食材新鮮度、過敏原、烹調熟度與個人健康狀況。
- 若涉及嬰幼兒、慢性病、孕期、藥物交互作用等情境，請優先諮詢專業人士。

## 2) 資料蒐集範圍

- 匿名 Web 工作階段識別（`chef_session` cookie 對應之 `user_id`）
- 對話內容與 AI 生成結果
- 使用者上傳圖片（若有）
- 收藏、方案狀態與每日用量資料
- **口味檔案**：過敏原、不愛／愛吃食材、飲食限制、菜系與烹飪偏好、家庭成員（含年齡層與飲食注意事項；醫療相關欄位僅用於推薦，不對外展示）

## 3) 資料用途

- 提供食譜生成與多輪對話服務
- 保存收藏與偏好設定
- **依你提供的口味與家庭成員資訊提供個人化推薦**（可於「口味檔案」`/app/profile` 查看、編輯、匯出或清除）
- 執行配額控管、訂閱管理與營運分析
- **主動效期提醒與週報**（若你開啟）：依冰箱庫存效期與通知偏好，於 App 內顯示提醒（非第三方推播除非日後另行取得裝置推播授權）

## 4) 刪除與查詢

- Web：於「口味檔案」可匯出 JSON 或清除所有個人化資料；於「偏好 → 通知與提醒」可關閉效期提醒、調整安靜時段或暫停推播；於「我的」可刪除帳戶與伺服器端全部資料。
- 系統將清除對話記憶、收藏、口味檔案、用量與訂閱關聯資料（依租戶範圍）。

## 5) 保存期限與最小化原則

- 僅保存必要資料，並應由營運方設定保存天期與自動清理機制。
- 生產環境日誌應避免記錄敏感個資，必要時採遮罩或去識別化。
